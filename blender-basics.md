## Що таке Blender?

**Blender** — це безкоштовна програма з відкритим кодом для 3D-моделювання, анімації, рендерингу та багато іншого. Вона використовується як професіоналами, так і початківцями по всьому світу.

> 💡 Blender можна завантажити безкоштовно з офіційного сайту: **blender.org**

---

## Інтерфейс Blender

Після запуску Blender ви побачите кілька основних зон:

| Зона | Призначення |
|------|-------------|
| **3D Viewport** | Головне робоче вікно — тут ви бачите та редагуєте свою сцену |
| **Outliner** | Список усіх об'єктів на сцені |
| **Properties** | Налаштування об'єктів, матеріалів, камери, освітлення |
| **Timeline** | Шкала часу для анімацій |

## Базові операції

### Виділення об'єктів
- **Лівий клік миші** — виділити об'єкт
- **A** — виділити все / зняти виділення
- **Shift + клік** — додати до виділення

### Трансформації
- **G** — переміщення (Grab)
- **R** — обертання (Rotate)
- **S** — масштабування (Scale)
- **X / Y / Z** — обмеження руху по осі (після натискання G, R або S)

### Додавання об'єктів
- **Shift + A** — відкрити меню додавання об'єктів (Mesh → Cube, Sphere, Cylinder тощо)

---

## Режими роботи

| Режим | Для чого |
|-------|----------|
| **Object Mode** | Робота з об'єктами як цілими одиницями |
| **Edit Mode** (Tab) | Редагування вершин, ребер та граней об'єкта |
| **Sculpt Mode** | Ліпка форми, як з глини |

---

## Перший проєкт: проста чашка

### Крок 1 — Створіть циліндр
1. Видаліть куб за замовчуванням (виділіть → **X** → Delete)
2. **Shift + A** → Mesh → **Cylinder**
3. У нижньому лівому куті налаштуйте: Vertices: **32**, Radius: **1**, Depth: **1.5**

### Крок 2 — Увійдіть в Edit Mode
1. Натисніть **Tab** для переходу в Edit Mode
2. Виділіть верхню грань (**Alt + клік** на верхньому ребрі)
3. **I** (Inset) — створіть внутрішню грань
4. **E** (Extrude) + **S** — видавіть вниз для створення порожнини

### Крок 3 — Додайте ручку
1. Поверніться в Object Mode (**Tab**)
2. **Shift + A** → Mesh → **Torus** (для ручки)
3. Масштабуйте та розмістіть тор збоку циліндра

## Корисні поради

- 🔄 **Ctrl + Z** — скасувати дію
- 💾 **Ctrl + S** — зберегти файл
- 📷 **Numpad 0** — переглянути через камеру
- 🎯 **Numpad .** — сфокусуватися на виділеному об'єкті

## Що далі?

Після опанування базових інструментів рекомендуємо:
- Вивчити **модифікатори** (Subdivision Surface, Mirror, Boolean)
- Спробувати **UV-розгортку** та **текстурування**
- Познайомитися з **матеріалами та шейдерами**
- Спробувати **рендеринг** у Cycles або EEVEE
