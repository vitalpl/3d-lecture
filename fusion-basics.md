# ⚙️ Основи Fusion 360

## Що таке Fusion 360?

**Autodesk Fusion 360** — це хмарна CAD/CAM/CAE-платформа для параметричного 3D-моделювання, інженерного аналізу та підготовки до виробництва. Безкоштовна для студентів та навчальних закладів.

> 💡 Fusion 360 ідеально підходить для проєктування деталей, які потім будуть надруковані на 3D-принтері.

---

## Інтерфейс програми

| Елемент | Призначення |
|---------|-------------|
| **Browser** (ліва панель) | Дерево побудови — список усіх операцій моделі |
| **Canvas** | Робочий простір для 3D-моделювання |
| **Toolbar** | Панель інструментів з основними командами |
| **Timeline** | Хронологія операцій внизу екрану |
| **ViewCube** | Навігаційний куб у правому верхньому куті |

## Основні концепції

### Параметричне моделювання

На відміну від Blender, у Fusion 360 ви працюєте з **параметричними ескізами**:
1. Створюєте 2D-ескіз на площині
2. Задаєте точні розміри та обмеження (constraints)
3. Перетворюєте ескіз у 3D-тіло за допомогою операцій

### Типи робочих просторів

| Простір | Для чого |
|---------|----------|
| **Design** | Основне моделювання деталей |
| **Render** | Візуалізація та рендеринг |
| **Animation** | Анімація збірок |
| **Manufacture** | Підготовка до ЧПУ або 3D-друку |
| **Drawing** | Створення креслень |

---

## Створення ескізу (Sketch)

### Початок роботи
1. Натисніть **Create Sketch** на панелі інструментів
2. Оберіть площину (XY, XZ або YZ)
3. Використовуйте інструменти малювання

### Основні інструменти ескізу

| Інструмент | Опис |
|-----------|------|
| **Line** (L) | Пряма лінія |
| **Rectangle** (R) | Прямокутник |
| **Circle** (C) | Коло |
| **Arc** | Дуга |
| **Fillet** | Скруглення кута |
| **Trim** (T) | Обрізка ліній |
| **Dimension** (D) | Задати розмір |

### Обмеження (Constraints)
- **Coincident** — збіг точок
- **Horizontal / Vertical** — горизонтальність / вертикальність
- **Parallel** — паралельність
- **Perpendicular** — перпендикулярність
- **Equal** — рівність розмірів
- **Tangent** — дотичність

## Основні 3D-операції

### Extrude (Видавлювання)
Перетворює 2D-ескіз у 3D-тіло, витягуючи його на задану висоту.

### Revolve (Обертання)
Створює тіло обертання навколо осі — ідеально для круглих деталей (вази, ручки).

### Fillet / Chamfer
- **Fillet** — скруглення ребер
- **Chamfer** — зрізання ребер під кутом

### Hole
Створення точних отворів з різьбою або без.

### Mirror / Pattern
- **Mirror** — дзеркальне відображення
- **Circular / Rectangular Pattern** — масив копій

## Перший проєкт: підставка для телефону

### Крок 1 — Базовий ескіз
1. Create Sketch → площина XY
2. Намалюйте прямокутник **80 × 60 мм**
3. Закрийте ескіз (Finish Sketch)

### Крок 2 — Видавлювання
1. **Extrude** → висота **10 мм**

### Крок 3 — Паз для телефону
1. Створіть новий ескіз на верхній грані
2. Прямокутник **70 × 4 мм** по центру
3. Extrude → **-8 мм** (вирізання вниз)

### Крок 4 — Скруглення
1. Виділіть зовнішні ребра
2. **Fillet** → радіус **3 мм**

---

## Експорт для 3D-друку

1. Правий клік на тіло в Browser → **Save as STL**
2. Оберіть одиниці вимірювання (мм)
3. Задайте якість мережі (High для точності)
4. Збережіть файл для подальшого слайсингу

## Що далі?

- Вивчіть **збірки (Assemblies)** — з'єднання кількох деталей
- Опануйте **параметричний дизайн** — зміна розмірів через параметри
- Спробуйте **Render** — фотореалістичну візуалізацію
- Підготуйте модель до 3D-друку через **Manufacture**
